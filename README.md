# Project Setu

A 240-day journey from Python to a multi-agent research system, built one committed day at a time.

- **The plan:** `docs/00_MASTER_PLAN_DS_GENAI.md`
- **The day map:** `docs/CURRICULUM_INDEX_DS.md`
- **Start here:** `days/day-00-setup/LESSON.md`

## Daily rhythm

```bash
./m status      # where am I
./m start N     # open day N's hub, and list its parts
./m scaffold N  # create day N's lab folder
./m check       # lint + format + offline tests
./m done N      # refuses to commit until the checklist is ticked and checks are green
```

## Rules this repo runs on

1. Every day produces committed, runnable code.
2. From scratch before library.
3. Exact version pins, committed lockfile, nothing floating.
4. A behaviour is not done until a test can go red when it regresses.
